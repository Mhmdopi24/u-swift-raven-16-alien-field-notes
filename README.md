A tiny Node program that writes one line — an alien tourist's field-note review of planet Earth, filed after two days of observing a human birthday — to `entry.txt` in the output directory, where the bounty's judge compares it pairwise against the other entrants' lines on funniness and originality.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
